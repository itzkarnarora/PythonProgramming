# 🐍 Welcome to Python Hangman Game!
A simple Hangman game built using Python as part of my journey to learn and practice programming.
The game selects a random word from a predefined list, and the player has to guess the word one letter at a time before running out of lives.

## 🎮 How to Play
1. Run the Python file.
2. A random word is selected by the game.
3. Enter a letter when prompted.
4. Correct guesses reveal the matching letters in the word.
5. Incorrect guesses reduce your remaining lives.
6. Guess the complete word before running out of lives to win!

## ✨ Features
- Random word selection using Python's `random` module.
- ASCII-art Hangman title and stages.
- Six lives to guess the word.
- Displays correctly guessed letters.
- Tracks previously guessed correct letters.
- Win and lose conditions.

## 🛠️ Requirements
- Python 3
No external libraries are required.

## 🚀 How to Run
**1. Clone the repository**
```bash
git clone <your-repository-url>
```
**2. Navigate to the project folder**
```bash
cd <your-project-folder>
```
**3. Run the game**
```bash
python hangman.py
```

You may need to use `python3 hangman.py` depending on your system.
