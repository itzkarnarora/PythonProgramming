# 🍕 PyPizza
A beginner-friendly Python project that calculates the final price of a pizza based on its size and selected toppings.

## How It Works
The program asks the customer to choose:
* Pizza size: Small, Medium, or Large
* Pepperoni: Yes or No
* Extra cheese: Yes or No

It then calculates the total cost based on the selected options and displays the final bill.

## Pricing
| Option                         | Price |
| ------------------------------ | ----: |
| Small Pizza                    |   $15 |
| Medium Pizza                   |   $20 |
| Large Pizza                    |   $25 |
| Small Pizza + Pepperoni        |   +$2 |
| Medium/Large Pizza + Pepperoni |   +$3 |
| Extra Cheese                   |   +$1 |

## Concepts Practiced

* `.upper()`

* `if`, `elif`, and `else`
