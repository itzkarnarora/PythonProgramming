# 🏝️ Treasure Island Game
A beginner-friendly text-based adventure game built with Python. Make the right choices to navigate through the island and find the hidden treasure!

## How It Works
The game presents the player with different situations and choices.
Your decisions determine what happens next:
* Choose a direction at the crossroads.
* Decide whether to wait for a boat or swim across the lake.
* Choose one of three doors on the island.
* Find the treasure by making the correct choices!

## Game Objective
Reach the **yellow door** without making the wrong choice to find the treasure and win the game. 🏆

## Concepts Practiced
* `input()`
* Variables
* `if`, `elif`, and `else`
* Nested conditional statements
* String handling
* User interaction
* Basic game logic

## How to Run
```bash
python main.py
```

## Example
```text
Welcome to Treasure Island!
Your mission is to find the treasure!

You are at a cross road. Where do you want to go? Type 'left' or 'right':
left

You come to a lake. There is an island in the middle of the lake.
Type 'wait' to wait for a boat. Type 'swim' to swim across:
wait

You arrive at the island unharmed. There is a house with 3 doors.
One red, one yellow and one blue. Which colour do you choose?
yellow

You found the treasure! You Win!
```
