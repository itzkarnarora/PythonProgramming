# 🧮 BMI Calculator
A beginner-friendly Python project that calculates a person's Body Mass Index (BMI) using their weight and height, then displays their BMI category.

## How It Works
The program asks the user for:

* Weight in kilograms
* Height in meters

It calculates the BMI using the formula:

```text
BMI = weight / height²
```

It then displays the calculated BMI and its corresponding category.

## Concepts Practiced
* `input()`
* `float()`
* Variables
* Arithmetic operations
* Conditional statements
* `if`, `elif`, and `else`
* f-strings

## How to Run
```bash
python main.py
```

## Example
```text
Enter your weight in kg: 70
Enter your height in meters: 1.75

Your BMI is: 22.86
You have a normal weight.
```
