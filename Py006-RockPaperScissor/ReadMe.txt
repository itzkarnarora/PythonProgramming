# ✊ Rock, Paper, Scissors
A beginner-friendly Python game where the player competes against the computer in the classic game of Rock, Paper, Scissors.

## How It Works
The computer randomly selects one of three choices:
* Rock
* Paper
* Scissors
The player enters their choice, and the program determines whether they **win, lose, or tie**.
The game continues until the player enters `exit`.

## Game Rules
* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Matching choices result in a tie

## Concepts Practiced
* `import`
* `random` module
* `random.choice()`
* `while` loops
* `if`, `elif`, and `else`
* Boolean conditions
* `break`
* `continue`
* User input
* String methods

## How to Run
```bash
python main.py
```
