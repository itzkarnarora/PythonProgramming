# 🔐 Python Password Generator
A beginner-friendly Python project that generates a random password based on the number of lowercase letters, uppercase letters, numbers, and special characters chosen by the user.

## How It Works
The program asks the user how many of each character type they want:
* Lowercase letters
* Uppercase letters
* Numbers
* Special characters
It randomly selects the requested characters, combines them into a list, shuffles their order, and generates the final password.

## Features
* Custom password composition
* Random character selection
* Randomized character order
* Supports letters, numbers, and special characters

## Concepts Practiced
* `import`
* `random` module
* `random.choices()`
* `random.shuffle()`
* Lists
* `extend()`
* `for` loops
* String manipulation
* User input
* Type conversion with `int()`
