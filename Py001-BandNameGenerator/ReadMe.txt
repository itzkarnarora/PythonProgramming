# 🎸 Band Name Generator
A simple beginner Python project that generates a possible band name using the user's birth city and first pet's name.

## How It Works
The program asks the user for:
* The city they were born in
* The name of their first pet
It then combines both inputs to create a suggested band name.

## Concepts Practiced
* `input()`
* Variables
* f-strings
* String concatenation
* Basic user interaction

## How to Run
```bash
python main.py
```

## Example
```text
What's the name of city you were born in? :
Delhi

What's your first pet's name? :
Max

Your band name could be Delhi Max
```
