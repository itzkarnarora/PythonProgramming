# 💰 Tip Calculator
A beginner-friendly Python project that calculates how much each person should pay when splitting a bill, including a selected tip percentage.

## How It Works
The program asks for:
* The total bill amount
* The desired tip percentage
* The number of people splitting the bill
It then calculates the total bill with the tip and divides it equally among everyone.

## Concepts Practiced
* input()
* float() and int()
* Variables
* Arithmetic operations
* f-strings
* Basic calculations

## How to Run
```bash
python main.py
```

## Example
```text
What was the total bill? $
100

What percentage tip would you like to give? 10, 12, or 15?
10

How many people to split the bill?
4

Each person should pay: $27.5
```
